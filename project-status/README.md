# Game Engine current state

The Windows Editor, native Player, compiler, and headless runner already share an authored project model and gameplay
registration. The Editor can build scenes and reusable Props, save and recover edits, and launch Play or export. The
current checkout adds Scene Flow and streaming, viewport inspection modes, startup and mouse-input improvements, and The
Hollow Maze sample. The Agent explains the current project and external MCP clients can inspect it with consent. Asset
generation and reviewed scene composition are the next capabilities. [Development roadmap](development-roadmap.md)
