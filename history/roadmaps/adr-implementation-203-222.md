# Architecture implementation roadmap, Milestones 203–222

This pass compares ADRs 0001–0010 with the Editor, engine and Player at
commit `ad909d9`. Existing GLB import, linked Props, Animator, Controls
Graph, typed native scripts, keyboard/gamepad controls, Play isolation and
Windows export are the starting point.

The order places saveable editor changes, backward-compatible identities
and validated runtime boundaries ahead of features that depend on them.
The table records implementation and acceptance per feature. A milestone
remains open until its acceptance check passes or its recorded decision
gate resolves it.

## Decisions to keep tied to evidence

Binary transport, a parallel scheduler, a replacement physics engine, a
general scripting VM, Prop variants and multi-player device pairing remain
design choices. Evaluate each against the corresponding finished workflow
and measured need. Keep the existing native mechanisms as the baseline for
those comparisons.
